保存在设备上的数据

修真无需注册 App 账号。App 在设备上保存入定和历练记录、学习进度、录入或导入的文章和笔记、照片与设置，以便显示进度、回看路线、练习和恢复使用状态。启用桌面小组件时，App 和小组件在设备上共享显示所需的进度信息。

开始 GPS 历练后，App 使用系统定位记录路线、计算里程和关联留影位置。在系统授权允许的情况下，进行中的历练可以在锁屏或切到后台后继续记录。结束历练可停止这一会话的定位记录。选择拍摄或从相册选取照片时，App 处理你选定的图像并把副本存为历练留影。拍摄留影时，App 可在系统授权允许的情况下获取一次位置用于标注照片。选择朗读时，App 使用 iOS 语音合成朗读文字。启用提醒后，App 使用系统本地通知按设定时间提醒你。

自愿加入的总榜与本机身份

你可以建立本机修行身份，设置仅留在设备上的私密称呼，并选择内置头像。境界、累计入定时长和累计历练里程三个总榜默认关闭；创建身份本身不会注册到服务器。你逐榜确认加入后，我们才传输并保存随机公开 ID、系统道号编号、内置头像编号和该榜当前成绩，以及身份验证哈希、版本和同步时间。其他未加入榜的成绩、日记录、GPS 点、照片、文章和私密称呼不会上传到榜单服务器。随机 ID 与成绩有关联，因此不称为匿名数据。

榜单向其他用户展示系统道号、内置头像、所选榜成绩和排名。它不含聊天、自定义公开文字或上传头像。退出一个榜会移除该榜成绩；删除榜单身份会移除服务器身份和全部成绩，不改变本机修炼资料。网络失败时请求会保留为待处理，确认前可能仍在榜。删除后保留不可公开的 ID 撤销摘要和二次凭据撤销摘要，用于阻断旧请求重建，保留至服务终止；不保存原始秘密或已删成绩。

本机凭据由系统安全存储保护，不进入普通导出。身份和参与选择不随普通备份导入，不支持账号登录找回或换机恢复。卸载不等于服务器删除；请先在设置页删除榜单身份。如设备丢失，可联系运营者请求协助核实和处理。榜单服务托管于腾讯云美国硅谷节点，数据会传输至美国处理。管理员可为处理用户请求或核对数据暂停/恢复公开展示，或删除榜单身份；这些操作不会直接更改你的本机记录。管理操作记录不含私密称呼或成绩，只保留目标 ID 的不可逆摘要、管理员、操作分类和时间；管理界面展示最近 30 天，过期记录在后续管理操作或查询时清理。传输使用 HTTPS，服务器限制数据库访问，管理入口要求身份验证。所在地区的数据保护规则可能不同；这些技术措施不意味着我们已取得任何特定跨境认证。部署维护时可能制作受限访问的数据库快照，删除操作不会自动逐份清除已有快照；恢复前须重放最新退出、删除及撤销状态，防止已删除身份重新公开。

连接外部服务时

  • 在线底图。 打开含位置的轨迹回看时，设备可能直接向 Esri ArcGIS 请求地图瓦片。请求包含缩放级别和瓦片行列坐标，可能反映当前显示的路线或照片所在区域。Esri 也会收到 IP 地址等网络请求信息。修真在设备上绘制轨迹和照片标记。地图请求本身不包含完整 GPS 点序列、留影文件或学习记录。Esri 在其隐私声明中说明可能记录 IP 地址等访问数据。接收方为 Esri（Environmental Systems Research Institute, Inc. 及相关关联方）。我们无法控制其日志保留期限，也未取得该瓦片端点的专用保留期限说明；处理方式以 Esri 的适用政策和条款为准。可向 privacy@esri.com 查询或提出访问、更正、删除请求。Esri 隐私声明
  • 网页导入与访问。 在心法阁输入链接并选择读取或打开网页时，设备会访问你指定的网站及其跳转目标。目标站点会收到 IP 地址等请求信息。使用内置网页时，网页及其加载的第三方资源也可能使用 Cookie 或类似技术，受各站点的政策约束。读取到的文字在你保存后进入设备上的心法阁。
  • 主动分享和备份。 你可以选择将记录导出到文件或交给系统分享。包含留影的历练数据文件可能含路线坐标、时间和照片。你选择的接收方或存储服务按其政策处理所收到的副本。删除 App 内记录不会移除已经导出的文件或他人收到的副本。
  • 联系支持。 你来信时，运营者会使用你的联系信息和你选择提供的内容来回复、排查问题或处理隐私请求。支持来信及相关处理材料在问题处理完成后最多保留 180 天，你可通过上述邮箱申请提前删除；法律要求保留的资料仅在所需范围和期限内继续保存。

本支持网站

本公开说明网站由 GitHub Pages 托管。页面不设分析脚本、广告、表单或第三方字体，也不主动设置 Cookie。GitHub 会为安全目的记录并保存访客的 IP 地址，无论访客是否登录 GitHub；其处理受 GitHub 隐私声明 约束，我们不能替 GitHub 指定日志保留期限。此网站不接收你的路线、照片或榜单身份。旧服务器地址可继续提供相同说明；该自管站点及榜单服务未启用逐 HTTP 请求访问日志，系统日志可能包含运行或安全故障信息。邮件由你选择的邮件服务和运营者使用的 QQ 邮箱处理，各自服务商按其政策提供邮件传输和存储。

管理权限和删除

你可以在 iPhone 或 iPad 的「设置」中调整定位、相机、照片和通知权限。撤回权限会影响后续相关操作，已经保存的记录仍可通过 App 内相应功能管理。

在道录中可删除历练记录和留影。删除一条历练时，其照片会移到「未归属留影」，可从那里逐张删除。在心法阁中可删除心法。设备上的 App 数据保留至你删除对应内容或使用系统的「删除 App」移除应用及其本地数据。设备备份、相册原图和主动导出的副本需在各自位置管理。如需访问、更正或删除你向运营者提供的数据，或询问第三方请求的处理方式，请发送邮件至上述隐私联系邮箱。
